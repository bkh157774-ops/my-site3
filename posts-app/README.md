# 🚀 Lumae Posts - Система постов

Полная система социальной сети постов с сервером на Python и базой данных SQLite.

## 📋 Что это включает?

✅ **Фронтенд** (`index.html`) - красивый интерфейс для создания и просмотра постов
✅ **Бэкенд** (`main.py`) - сервер на Python с FastAPI
✅ **База данных** (`posts.db`) - SQLite для хранения постов

## 🔧 Как запустить?

### 1️⃣ Установить Python зависимости

```bash
pip install -r requirements.txt
```

### 2️⃣ Запустить сервер

```bash
python main.py
```

Сервер запустится на `http://localhost:8000`

### 3️⃣ Открыть в браузере

Откройте файл `index.html` в браузере или перейдите на `http://localhost:8000`

## 🌐 Как это работает?

```
┌─────────────────────┐
│   Браузер (HTML)    │  ← Интерфейс для пользователя
│   (index.html)      │
└──────────┬──────────┘
           │ Запросы (HTTP)
           ↓
┌─────────────────────┐
│  Сервер (FastAPI)   │  ← Обработка запросов
│   (main.py)         │
│  Порт 8000          │
└──────────┬──────────┘
           │ Чтение/Запись
           ↓
┌─────────────────────┐
│  База данных        │  ← Хранилище постов
│  (posts.db - SQLite)│
└─────────────────────┘
```

## 📡 API Endpoints

| Метод | Endpoint | Описание |
|-------|----------|---------|
| GET | `/api/posts` | Получить все посты |
| POST | `/api/posts` | Создать новый пост |
| GET | `/api/posts/{id}` | Получить пост по ID |
| DELETE | `/api/posts/{id}` | Удалить пост |
| POST | `/api/posts/{id}/like` | Лайкнуть пост |

## 🐛 Решение проблем

### Ошибка CORS?
Сервер уже настроен для работы с браузером.

### Сервер не запускается?
Проверьте, что Python 3.8+ установлен:
```bash
python --version
```

### База данных не создаётся?
Она создаётся автоматически при первом запуске сервера.
